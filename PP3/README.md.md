## **Preguntas y Respuestas**


### 1. Si tuviera que implementar una estructura tipo Cola (Queue), ¿qué tipo de lista utilizaría y por qué? ¿Y para una estructura tipo Pila (Stack)?

**Respuesta:** Para una Cola usaría una lista simplemente enlazada con referencia al último nodo, ya que ofrece O(1) en encolar y desencolar siendo eficiente en memoria. Para una Pila también elegiría lista simplemente enlazada, pues al manejar solo el tope, push y pop son O(1) con implementación simple y rápida.

### 2. ¿Cuál cree que podría ser una ventaja y una desventaja de utilizar una estructura de tipo lista creada por usted mismo, en vez de las opciones proveídas directamente por los módulos estándar de Java?

**Respuesta:** La ventaja es el control total para optimizar según necesidades específicas de rendimiento. La desventaja es el mayor desarrollo y pruebas requeridas versus usar las Collections ya probadas de Java.
